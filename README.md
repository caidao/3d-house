# 彩光城堡 · 小小建筑师

根据提供的磁力贴建筑照片重新设计的可交互 3D 建筑网页。保留彩色尖塔、深色坡屋顶、星形塔楼和空中连廊，加入实墙、落地窗、三米层高的室内空间、家具、楼梯与楼板开口、阳台护栏、庭院围墙、泳池和照明。场景采用本地 PBR 石材/木材/地面纹理、HDR 环境照明和环境遮蔽；不是施工图或结构安全设计。

## 运行

`npm start` 后打开 http://localhost:4173/ 。无需安装依赖；Three.js 0.180.0 已随静态资源保存，并包含 MIT 许可证。

## 操作

拖动旋转，滚轮缩放，触屏单指旋转、双指平移或缩放。支持全景、正面、俯瞰、庭院及客厅视角、日夜切换、自动旋转与重置。聚焦画布后可用方向键旋转，加减键缩放。原作弹窗支持 Escape 关闭。

## 验证

`npm test` 检查模型几何坐标、实例化植被、建筑边界、楼梯踏步尺寸、实际光源和完整的本地模块依赖及材质文件。`node --check dist/app.js` 检查交互代码语法。另已验证渲染模块导入和静态几何合并。已在本地浏览器检查全景与庭院画面，验证日夜切换、自动旋转、重置及原作弹窗，并检查控制台无报错。仍未达到用户参考图的照片级写实度；尚未逐项验收移动端。

## 文件

- `dist/index.html`：页面内容与无障碍控件。
- `dist/style.css`：桌面与移动布局。
- `dist/scene.js`：建筑、庭院及材质。
- `dist/app.js`：HDR/PBR 加载、渲染后处理、几何合并、相机与交互。
- `dist/assets/materials/SOURCES.md`：Poly Haven CC0 材质来源。
- `dist/assets/original.png`：用户提供的参考照片。

照片仅用于本网站中的原作对照。网站默认私有。

## 参考图还原边界

此版本修复了过远镜头和前景植物遮挡，重建了展开式五段长廊、下层房间、弧形玻璃塔楼、绿色观景球、彩色踏步和小型吊臂，并使用扫描植物。建筑依然是程序生成的近似模型，屋顶结构、材质细节、植被密度与参考图存在明显差距，不能视为照片级还原完成。
