# 彩光城堡 · 小小建筑师

根据提供的磁力贴建筑照片重新设计的可交互 3D 建筑网页。保留彩色尖塔、深色坡屋顶、星形塔楼、空中连廊与环形道路，采用玻璃、金属与石材的概念建筑表达；不是施工图或结构安全设计。

## 运行

`npm start` 后打开 http://localhost:4173/ 。无需安装依赖；Three.js 0.180.0 已随静态资源保存，并包含 MIT 许可证。

## 操作

拖动旋转，滚轮缩放，触屏单指旋转、双指平移或缩放。支持视角预设、日夜切换、自动旋转与重置。聚焦画布后可用方向键旋转，加减键缩放。原作弹窗支持 Escape 关闭。

## 验证

`npm test` 检查模型几何坐标、材质、建筑高度与地面边界。`node --check dist/app.js` 检查交互代码语法。本次未执行浏览器逐项交互及截图验证。

## 文件

- `dist/index.html`：页面内容与无障碍控件。
- `dist/style.css`：桌面与移动布局。
- `dist/scene.js`：建筑、庭院及材质。
- `dist/app.js`：渲染、相机与交互。
- `dist/assets/original.png`：用户提供的参考照片。

照片仅用于本网站中的原作对照。网站默认私有。
