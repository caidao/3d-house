# 磁力城堡 · 小小建筑师

基于用户最初提供的四个不同角度的磁力贴实物照片制作的可交互三维网页。外观复刻约束记录在 [docs/exterior-reference.md](docs/exterior-reference.md)。不再按普通玻璃住宅重新设计外部。

## 当前外部内容

- 方形与三角磁力片、红色收尖塔、蓝黄展开塔帽、星形放射塔、黑框圆弧片、绿色圆弧门廊。
- 八块道路坡屋顶、道路白边与虚线、绿色箭头、彩色冠顶、黄色黑色双折线护栏、红砖图案片。
- 分段的银色棱面连廊，两台黄色吊机、绿色半球、人物立牌和左粉右蓝的磁力阶梯组件。
- 六条院内道路路线，包括前方道路、椭圆路环、左右环路和门廊道路。
- 入口红白路障、黄黑立柱、三角及圆形交通牌、停车标志、红绿灯、锥桶、车辆队列和彩色拼片围栏。
- 撤去此前擅自添加的泳池、喷泉、湖泊、石砌围墙和独立庭院家具。树木仅作为模型场地之外的环境背景；室内布局独立设计。

## 比例与还原边界

以一块方形磁力片为一个模块，使用统一放大比例。模块尺寸用于可视化，没有现场实测依据；不能将模型称为已测量验证的精确一比一建筑。遮挡面及部分贴片连接仍未逐片核实；照片级材质效果也尚未达到后续参考效果图。外部磁力阶梯保留组件轮廓，室内步行楼梯独立制作。

## 运行与操作

`npm start` 后打开 http://localhost:4173/ 。无需安装运行依赖。拖动旋转、滚轮缩放，或使用全景、正面、俯瞰、庭院、客厅按钮。聚焦画布后方向键旋转，加减键缩放。支持日夜切换、自动旋转、复位。原作对照支持四个拍摄角度，Escape 关闭。

## 验证

`npm test` 检查有限几何坐标、建筑边界、室内楼梯尺寸、原作主要构件、道路路线、双色阶梯，以及完整本地模块和资源依赖。

浏览器已检查模型加载与可见外观，并验证原作四角度切换。此前已验证旋转、复位和日夜切换；当前版本交付前再次检查。上述检查不等同于逐片照片比对或真实建筑结构审查。
