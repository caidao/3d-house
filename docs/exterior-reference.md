# 外观复刻约束

用户要求：原作整体等比例放大，外部磁力片形状、颜色、组合、吊机、道路、路障及交通指示牌都保留；仅室内布局可自行设计。

以最初提供的四个不同视角实物照片为外部结构依据。后续建筑效果图用于核对“放大后的视觉呈现”，不能用其新增景观替换实物搭建。

| 部位 | 原作中可观察的特征 | 实现要求 |
| --- | --- | --- |
| 主楼 | 多层方形拼片、银色菱面片、道路坡屋顶、三角冠顶 | 不改成普通玻璃幕墙和光伏屋顶 |
| 左侧塔 | 上窄下宽的红色长三角尖塔、蓝黄向上展开的顶片 | 不替换为普通圆锥顶 |
| 星形塔 | 红、橙、黄、青色放射三角片，黑框圆弧片 | 不替换为圆柱加小尖顶 |
| 圆弧门廊 | 深灰半圆弧顶、绿色方片门架 | 保留独立构件 |
| 右侧连廊 | 阶梯式方片与银色多面顶片、彩色三角侧片 | 不改成一整面平玻璃斜屋顶 |
| 末端楼梯 | 左粉色、右蓝色两块磁力阶梯组件 | 不改成横向彩虹配色 |
| 吊机 | 黄色转台、折臂、悬挂钩，分布在主楼前及连廊上 | 保留外形与相对位置 |
| 立面装饰 | 黄黑导向护栏、红砖图案、人物立牌 | 保留作为建筑表面组件 |
| 道路 | 黑色模块、白边与虚线、左右环路、前方椭圆路环 | 不替换为泳池、喷泉或草坪环岛 |
| 交通设施 | 红白栏杆、黄黑立柱、圆形/三角交通牌、红绿灯、锥桶、车辆队列 | 按照片可见内容布置 |
| 前方围栏 | 彩色拼片围栏与道路入口 | 不用新增石墙封闭道路 |

## 比例及证据边界

- 统一以一片方形磁力片为一个模块；模型采用同一放大比例。模块长度是可视化比例，照片未提供实物尺寸，不能宣称已获得测量级尺寸。
- 可见外观按实物照片复刻；被遮挡的拼片边界和颜色应明确保留为未验证内容，不能用“已完成一比一”概括。
- 放大后的外部磁力阶梯仍保留原作组件轮廓；室内实际步行楼梯另行布置，不改变外观组件的阶数。
- 此文件记录当前请求的外观验收依据，不表示已经完成照片级或逐片测量级验收。
